# Project overview

LangChain Playground is a Python project for exploring AI agents with LangChain and LangGraph.

- `agents/`: Python agent applications. `agents/src/agent_quickstart/`, `agents/src/agent_langgraph/`, and `agents/src/agent_skills/` contain separate examples.
- `docker/`: Docker setup for running the applications with PostgreSQL support; includes a Makefile.
- `README.md`: Project overview. See `agents/README.md` and `docker/README.md` for area-specific documentation.
